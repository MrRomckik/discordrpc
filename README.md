#EN
To work, install Python:
https://www.python.org/ftp/python/pymanager/python-manager-26.3.msix (Windows)
https://www.python.org/ftp/python/3.14.6/python-3.14.6-macos11.pkg (MacOS)

Launch the application by right-clicking and selecting Python, or simply double-clicking the program.
You can also launch it via PowerShell by simply specifying the full path to the file and prepending "Python"
(On MacOS, run only via terminal!).

#RU
Для работы, установите Python:
https://www.python.org/ftp/python/pymanager/python-manager-26.3.msix (Windows)
https://www.python.org/ftp/python/3.14.6/python-3.14.6-macos11.pkg (MacOS)

Запустите приложение, щелкнув правой кнопкой мыши и выбрав Python, или просто дважды щелкнув по программе.
Вы также можете запустить его через PowerShell, просто указав полный путь к файлу и добавив в начало Python
(В MacOS запускать только через терминал!).
